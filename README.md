## How to Create a Github Page
1. Make sure your project is pushed to a GitHub repository.
2. Go to your repository on GitHub.
3. Click on **Settings** → **Pages**.
4. Under **Source**, select the branch you want to deploy.
5. Click **Save**. GitHub will provide a link to your live website.
6. Wait a few minutes for the site to publish. All done.
